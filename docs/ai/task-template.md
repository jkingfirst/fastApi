## 使用边界

- 未获明确实施批准时，只进行分析、计划和只读检查。
- Git commit、push、破坏性数据库操作及生产操作需要单独授权。
- 纯解释、只读分析或状态查询可省略不相关字段。
- 涉及项目运行、测试或迁移时，参阅 [开发与维护流程](development-workflow.md)；架构和既有风险分别参阅 [当前架构说明](architecture.md) 与 [代码审计报告](audit-report.md)。
